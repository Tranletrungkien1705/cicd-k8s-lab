3 · Khái niệm cốt lõi

6 mảnh ghép của một pipeline hiện đại:

CI Continuous Integration

Có code mới → tự test + build thành Docker image. Bắt lỗi sớm, luôn có bản sạch.

CD Continuous Deployment

Sau CI, tự phát hành ra môi trường chạy — không bấm tay.

Container Docker

Đóng gói app + mọi thứ nó cần vào 1 "hộp" chạy giống nhau ở mọi máy. Image = khuôn; Registry = kho.

Kubernetes orchestration

Chạy & quản lý container: Deployment, Service, Ingress, rolling update (zero-downtime), health probes.

GitOps Argo CD

Git là nguồn sự thật. Argo so Git vs cluster, lệch thì tự sync. Rollback = git revert.

Observability Prometheus/Grafana

App phát metrics ở /metrics → Prometheus thu → Grafana vẽ biểu đồ.
